# 관리자 3D 도서 표지

도서 등록 및 도서 수정의 「본문과 표지」에서 「3D 표지 만들기」를 연다. 도서명·저자명은 서지 정보에서 가져오며 클래식·모던·문학 템플릿과 숲·밤·와인 색상을 조합한다. 미리보기를 마우스나 손가락으로 드래그해 360° 돌리고 위아래로 기울인다. 방향키(Shift 조합 시 더 크게 회전), Home(정면), 앞표지·책등·뒷표지·종이 면 버튼과 슬라이더도 사용할 수 있다. 각도와 전체 두께를 조절하고 「이미지로 적용」을 누른 뒤 도서를 저장한다. 기존 도서는 같은 화면의 「3D 표지 다시 편집」에서 설정을 불러온다. 편집 취소는 기존 표지 또는 적용해 둔 미리보기를 보존한다.

## 책 형태와 재질

[Complete Shelf](https://play.mint.gg/complete-shelf)의 MIT 공개 구현에서 둥근 양장판·책등·머리띠 구조와 조명/소재 값을 가져와 적용했다. 약 131×220mm 비율에 기본 전체 두께 27mm, 표지판 3.4mm, 안쪽으로 들어간 크림색 종이, 작은 표면 잔결과 낮은 광택을 사용한다. 앞뒤 표지와 책등에는 관리자가 선택한 팔레트와 문구를 사용한다. 원본의 개별 도서 삽화나 브랜드 자산은 포함하지 않는다. [라이선스](licenses/mint-complete-shelf.txt)를 함께 보관한다.

회전은 -180~180°, 위아래 기울기는 -90~90°다. 편집기에서 선택한 방향 그대로 PNG와 설정을 저장하며 다시 열면 복원한다. 과거 저장물에 기울기 값이 없으면 8°로 복원한다. 두께·각도 변경 시 표지 그림을 재생성하지 않고, 변경이 있을 때만 다시 그린다. 회전 중에도 책이 잘리지 않도록 촬영 거리를 맞춘다.

## 저장과 배포

- 운영 배포 전에 `20260910000001_book_cover_design.sql`을 적용한다. 기존 도서의 이미지·설정은 바꾸지 않는 nullable 컬럼 추가다. 기존 앱과 공존할 수 있고, 새 관리자 앱이 먼저 올라가면 컬럼 조회가 실패하므로 DB를 먼저 적용한다.
- 편집 설정과 PNG 주소는 같은 도서 저장에서 갱신된다. 일반 서지 정보 수정은 설정을 유지하고 수동 이미지 교체는 설정을 비운다.
- 매번 고유 이미지 경로를 사용한다. 저장 실패 시 새 표지 파일을 회수하며 기존 표지는 손상하지 않는다. 새 주소 저장 후 이 도서에 속한 이전 파일만 회수한다. 동시에 다른 편집에서 표지가 바뀌면 덮어쓰지 않고 다시 열도록 안내한다. 저장소의 회수 요청 자체가 실패하면 로그를 남기며 도서 저장 결과를 되돌리지 않는다.
- 생성 PNG는 800×1200, 투명 배경이다. 기존 사용자 커버 영역과 같은 2:3 비율이므로 입체 책을 잘라내지 않고 표시한다. 사용자 앱에 3D 라이브러리를 추가하지 않는다.
- 이미지 최대 2MB, 서버 제출 전체 최대 4MB다. EPUB을 함께 올릴 때도 제출 전체 한도가 적용된다.

## 검증

`packages/shared/src/cover-design.test.ts`는 편집 설정 복원과 잘못된 입력 거부를 검증한다. `e2e/admin.cover.spec.ts`는 신규 생성·저장·기존 도서 재편집·일반 표지 교체·서지 수정 후 설정 유지·미적용 저장 방지·제목 변경 후 재적용·취소를 실제 로컬 DB와 브라우저에서 확인한다. 마우스·방향키·실제 터치 입력의 회전, 앞뒤 각도와 기울기의 DB 저장·복원도 확인한다. 앞·뒤·책등·종이·위·아래 방향을 각각 내보내고 PNG의 크기·투명도·불투명 픽셀 수·네 변의 여백을 읽어 빈 이미지나 잘린 이미지가 아닌지 확인한다. 375px와 넓은 화면 캡처는 `.tmp/cover-verification/`에 둔다.

3D 그래픽을 지원하지 않는 브라우저에서는 오류 안내와 기존 업로드 경로를 제공한다. 한글 글꼴 로딩 후 그리며 그래픽 연결이 끊기면 편집기를 다시 열도록 안내한다.

2026-09-10 로컬 검증: 단위 검사 321개, 양쪽 앱 브라우저 검사 23개, 실제 DB 연동 7개, 기존 화면 비교 24개 통과. 신규 편집기는 별도로 375px 및 데스크톱에서 확인했고, 그래픽 사용 불가 시 업로드로 돌아가는 흐름도 브라우저에서 확인했다. 기존 화면 비교는 첫 화면 기준이므로 아래쪽의 새 편집기를 검증하는 별도 캡처와 함께 본다. 독서/순위 데이터가 달라지는 동작 검사 뒤에는 문서의 검증 순서대로 시험 데이터를 다시 준비하고 화면 비교를 실행했다. 운영 DB 적용과 운영 배포는 이 검증에 포함하지 않는다.

## 운영 일괄 적용 기록

2026-09-10: 운영 DB의 도서 16권 전체에 이 편집기의 렌더러로 만든 800×1200 투명 PNG를 저장했다. 클래식 양장 템플릿, 제목에 따라 고정한 세 가지 팔레트, 회전 25°·기울기 8°·전체 두께 27mm를 사용했다. 편집 설정 저장용 마이그레이션도 운영 DB에 적용했다. 각 도서의 이미지 주소와 설정을 함께 갱신했고, 16개 공개 이미지의 바이트 일치·크기·투명 여백과 DB 설정을 확인했다.

원본 도서 데이터, 기존 이미지 파일, 생성 이미지와 처리 기록은 로컬 `.tmp/cover-batch-20260910/`에 보관한다. `books-before.json`은 변경 전 도서 데이터이며 `manifest.json`은 이전/새 이미지 주소와 설정, 파일 검증값을 담는다. 기존 저장소 이미지는 삭제하지 않았다. 복구 시 이 기록의 이전 이미지 주소·설정만 해당 도서에 다시 적용할 수 있다. 관리자 편집 화면의 운영 배포는 이 일괄 이미지 적용과 별개다.
