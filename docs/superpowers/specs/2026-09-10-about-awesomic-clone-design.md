## 결정

### 1. 구조·비율·간격은 그대로, 문장은 똑똑의 것으로

참고 사이트의 문장(마케팅 카피·고객 후기·가격)을 그대로 옮기지 않는다. 실제
인물의 이름과 후기를 복제하는 것은 조작이고, 이 서비스는 한국어 단일(AGENTS.md)이다.
대신 **각 블록의 역할을 똑똑의 사실로 채운다**:

| 참고 사이트 블록 | 똑똑에서의 내용 |
|---|---|
| 고객 후기 카드 (이름·직함·인용) | **저작권 만료 작품의 문장** — 저자·작품명·첫 문장. 가짜 후기를 만들지 않는다 |
| 통계(20 000+, 4 000+, 70%…) | PRD·마이그레이션이 확인한 사실만 — 1962(§5.11 사망 연도 기준), 0원, 위키문헌 후보 365→329→293→290편(§11-65) |
| 인재 카드 (사진·이름·직무·경력) | 작품 카드 — 저자·작품·발표 연도·장르 칩 |
| 서비스 카드(웹·그래픽·모션…) | 똑똑의 화면 — 카드 피드·릴스·뷰어·도서 상세·탐색 |
| 요금제 | 이용 방식 3종 (전문 도서·링크형 도서·게스트) — 전부 무료 |
| 이메일 수집 폼 | **도서·작가 검색 폼** (`/discover?q=`) — 같은 모양이지만 실제로 동작하고, 이전 설계 비목표(이메일 수집)를 어기지 않는다 |
| FAQ | 첫 방문자의 실제 질문 7개 (무료인가, 왜 전문이 가능한가, 로그인 없이 되나…) |

### 2. 에셋 자리는 `AssetSlot` 하나로 통일한다

사진·영상·로고·질감(잔디) 이미지가 들어갈 자리는 `AssetSlot`이 같은 비율의 빈
면으로 예약한다. 채움은 `bg-muted`(밝은 표면 위) 또는 `bg-background/10`(어두운
카드 위), 라벨·점선 없음 — 사용자가 "안은 비워라"고 했다. `aria-hidden`이라
스크린리더는 빈 자리를 읽지 않는다. 비율을 예약하므로 나중에 이미지를 넣어도
레이아웃이 뛰지 않는다.

### 3. Tailwind 기본 스케일 + 임의값, 색은 토큰만

이전 결정 2·3을 그대로 따른다. 참고 사이트의 큰 라운딩(24~48px)·큰 활자(72px)는
`rounded-[2rem]`·`text-7xl`처럼 `/about` 안에서만 쓴다. 색은 `bg-card`(흰 면),
`bg-background`(회색 면), `bg-muted`(흰 면 위 회색 카드), `bg-foreground`+`text-background`
(검정 카드·버튼)만 쓴다 — 다크 모드가 공짜로 따라오고, 앱과 같은 무채색이다.
히어로의 회색 강조어는 `text-foreground/35`.

그림자는 쓰지 않는다(DESIGN.md Elevation). 참고 사이트의 버튼 광택·카드 그림자는
경계선으로 대신한다. **경계선은 토큰을 옅게 쓴다** — 참고 사이트 실측(2026-09-10)
으로 카드 테두리는 `rgb(236 236 238)`, 칩 테두리는 `rgb(228 228 231)`인데 `border`
토큰(oklch 0.9 ≈ rgb 224)을 그대로 쓰면 둘보다 진하다. 그래서 카드·프레임·구분선은
`border-border/60`(흰 바탕에서 ≈ 236), 칩·화살표 버튼·번호 원 같은 작은 요소는
`border-border/85`(≈ 228), 검정 카드 위 칩은 `border-background/20`이다. 토큰 값
자체는 건드리지 않는다 — 앱 화면의 경계선까지 옅어진다.

### 4. 상호작용은 최소 JS로

| 요소 | 구현 |
|---|---|
| FAQ·이용 순서 아코디언 | 네이티브 `<details>/<summary>` — JS 없음, `name` 속성으로 한 번에 하나만 열림 |
| 캐러셀 (서비스·작품·프로젝트·채널) | `overflow-x-auto` + `snap-x`. 화살표 버튼만 클라이언트 컴포넌트(`Carousel`) |
| 이용 방식 토글 (Launching/Scaling) | 클라이언트 컴포넌트 `ToggleChips`, `useState` |
| 검색 폼 | `<form action="/discover">` GET — JS 없음 |

### 5. 폰트 — Pretendard Variable

`next/font/local`, `weight: "45 920"`, `display: swap`, `--font-sans`에 바인딩.
가변 1파일(2.0 MB woff2)을 고른 이유: 정적 서브셋 4굵기(각 ~270 KB)보다 요청이
적고 모든 굵기를 쓸 수 있다. 소개 페이지가 400·500·600·700을 섞어 쓴다.
`Geist Mono`는 그대로. `--font-heading`은 `--font-sans`를 따르므로 손댈 것 없다.

16. 권리 확인 4단계 카드 (검정→흰, 수치)

**옮기지 않은 것**: 얼굴 이미지 위 회전 마스크(`rotateClip` 12s — 에셋에 얹는
